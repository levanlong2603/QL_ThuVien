GIAI THICH LOI BAN GAP:
- Ban dang vao thu muc app va chay: javac ThuVienApp.java
- Lenh nay chi bien dich 1 file, khong kem model/service/ui
- Vi vay Java bao loi "package ... does not exist"

NEU MUON CHAY THU CONG KHONG DUNG SCRIPT:
1) Tu thu muc goc D:\Documents\QL_ThuVien
2) Chay:
   Get-ChildItem -Recurse -Filter "*.java" | Where-Object { $_.FullName -notmatch "\\out\\" } | ForEach-Object { $_.FullName } | Set-Content sources.txt
   javac -encoding UTF-8 -d out "@sources.txt"
   java -cp out app.ThuVienApp
